## Description
This is the artefact for paper **Bypassing cMix and Other Practical Vulnerabilities** (PoPETs 2027). 

The `artefact/` folder contains execution logs from controlled experiments on a local cMixx cascade supporting V1 and V2, together with client-side logs and a network definition snapshot supporting the analysis of V3 and V4. The `README.md` maps each file to the corresponding claims.

The artefact contains recorded runtime logs as supporting our findings. It does not include executable PoC code for V1, V2 or the legacy V5 vulnerability.

### Security/Privacy Issues and Ethical Concerns

The artefact does not introduce risk to the evaluator, it contains no executable code and does not modify the evaluator's system. 

The logs were generated in a local environment with no sensitive data/credential; The network definition file contains node metadata publicly distributed by the xx network.

## Environment

No execution environment is required. The artefact consists of plaintext files only that can be inspected with a text editor or command line tools.
